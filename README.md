## Ответы на вопросы

1. > Что такое абстрактный класс? Почему нельзя написать Character() напрямую?

Абстрактный класс - это шаблон для классов-наследников. Он часто содержит абстрактные методы, которые необходимо переопределять наследникам, поэтому создать просто класс `Character()` нельзя, компилятор просто не поймёт, что делать с 

2. > Зачем нужен super в конструкторе наследника? Что будет если его убрать?

`super` необходим для обязательных параметров в классе родителя, чтобы конструктор наследника вызывал конструктор родителя. Удаление его приведёт к ошибке и код не скомпилируется. 

3. > В чём разница между @override у attack() в Warrior и takeDamage() в Warrior? Почему второй переопределяет метод который уже имеет реализацию в родителе?

`@override` у `attack()` реализует с нуля метод на основе абстрактного, а у `takeDamage()` переопределяет метод, давая ему новый функционал.

4. > Функция fight(Character a, Character b) не знает кто реально придёт — Warrior, Mage или Archer. Как называется эта концепция и где вы её уже видели во Flutter?

Эта концепция называется полиморфизм. На вход функции может прийти любой тип персонажа, и функция их примет, так как работает с общим классом. Во Flutter полиморфизм используется повсеместно, для построения виджетов.

5. > Что означает _random с нижним подчёркиванием в классе Character?

`_random` - это приватная переменная, доступная только внутри файла, где была объявлена. Это значит, что обратиться из другого файла к этой переменной не выйдет.
